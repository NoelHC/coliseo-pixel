# Colosseum Pixel

WHO WINS? A pixel-art arena game: pick the side you think wins, send helpers, throw powers.

- Play: https://noelhc.github.io/coliseo-pixel/
- Sandbox (drop any fighter, faction wars on loop): https://noelhc.github.io/coliseo-pixel/sandbox/
- Gallery (every fighter standing on the sand): https://noelhc.github.io/coliseo-pixel/gallery/

This repo only holds the built game (the page GitHub Pages serves).
